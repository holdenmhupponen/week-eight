This week our exercises consisted of building a language model inside Google Colab, and using an image classifier language model to look at similarities between images. I got through both of these with little error. For the first one, I did find a frustrating dead-end that I couldn't bypass, and resorted to using the Gemini built-in feature. I think this relates to what Perry explains as "enchantment." The A.I. made the process more accessible for me, as someone without programming experience, but at the same time took away the mental problem-solving of actually fixing the error myself. As for the image classifiers, it was really cool to upload a bunch of images and see the ostensibly simple script see differences. Though as Magani, Matthew, and Jon Clindaniel say, the machine learning nature of these tools means that the elitist and monocultural past of archaeological study makes archaeological machine learning inherently contributive to those issues. We should definitely be aware of that when working with such tools.
